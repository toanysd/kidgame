🚀 Bắt đầu điều khiển PC

Để Web AI có thể bấm phím giả lập trên máy tính Windows, bạn cần chạy Python Server cục bộ.

# Mở Terminal / CMD tại thư mục dự án và chạy: cd apps/kidgame/AIGamepad/server pip install websockets pydirectinput python server.py

Đảm bảo server báo "Đang lắng nghe kết nối tại: ws://localhost:8765" trước khi nhấn Tiếp tục.
